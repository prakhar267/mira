# Privacy

The product is designed around visible, user-controlled continuity. Users can inspect, edit, pin, delete, or pause memories; export local demo data; and delete the local demo profile.

Prototype data is stored in browser local storage or the in-memory API repository. Mock chat processing is local and deterministic. No external AI, voice, media, billing, or notification processor is called by default.

Production launch requires a reviewed privacy notice, consent ledger, verified identity and recent re-authentication for sensitive actions, processor agreements, purpose limitation, retention by data category, portable private export, deletion across primary and backup systems, access logs, and incident-response evidence.
