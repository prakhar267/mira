## Delivered source changes

1. **Genuine incremental text chat.** The actual route streams checked complete-sentence prefixes to the browser over NDJSON. One sentence is retained as lookahead. The real HTTP regression observes the first displayed prefix before the upstream provider completes. Only a validated terminal `done` commits an assistant reply; errors, cancellation and navigation discard the unsaved draft. Consent and selected memories are rechecked at each delivery boundary. Transport/frame limits, eight-prefix cap and a 15-second delivery deadline bound malformed streams and non-reading clients. One-sentence replies can still wait until completion. Voice/video retain the complete-reply path and the existing Priya voice; raw tokens are not played aloud. See [streaming boundaries](INFERENCE-BOUNDARY.md).
2. **Encrypted account archive and controlled recovery tooling.** AES-256-GCM chunks/manifests, a transactional minimal deletion/privacy journal, separate filesystem vault adapters, bounded export leases, quarantined targets, latest-suppression replay and password reset/reverification. A fresh target-bound proof retires the surviving source before cutover. The test deletes the synthetic source file only after capturing that proof. This is **not source-loss DR without current independent deletion evidence**, and no production archive is active. See [backup operations and limitations](ENCRYPTED-BACKUP-OPERATIONS.md).
3. **Accessibility fixes and broader browser checks.** Repaired contrast on public/auth pages, home, tabs, wardrobe, modal descriptions and floating call controls. Added an explicitly focusable skip link, a labeled/disabled hidden upload input, keyboard-scrollable call captions and dark-call-specific readable colors. Tests cover public pages, all five main views, profile/memory dialog, 320px chat reflow, doubled actual computed text sizes, keyboard navigation, and voice/video permission-error controls. Automated Axe checks preserve incomplete/manual-review findings; no rules are excluded to obtain a pass.
4. **Measured loading improvements.** Public links no longer prefetch the companion application, and the below-the-fold portrait is lazy-loaded with intrinsic dimensions. Initial decoded JavaScript fell from 801,236 to 320,746 bytes in the diagnostic runs (about 60%). The 1,965,219-byte offscreen portrait no longer loads initially. The 2,224,077-byte hero image still needs optimization for weak connections. Three throttled local observations do not establish P95, production Core Web Vitals, mobile hardware performance or call latency. See [recorded measurements](../audit/readiness-2026-09-13-followthrough/mobile-emulation.json).
5. **Truthful public copy and operator status.** The site explicitly distinguishes saved memories from unavailable automatic extraction and local camera preview from unavailable camera understanding. Operator reporting distinguishes an encryption key from an independent, verified backup system.
6. **Reliable test infrastructure.** The synthetic Worker framework now schedules background work with the real request's `ctx.waitUntil`; an explicit drainage regression covers it. The earlier throwing scheduler left abandoned tasks and caused a subsequent Worker read to hang in the harness. No production-storage workaround was added. Browser/artifact runners execute installed CLIs under the pinned Node runtime, without nested package-manager installs into each isolated cache. This preserves credential isolation and the inference shutdown probe.
