# Mira 3D avatar asset

The `mira-avatar.glb` model and its texture files are derived from
`Female_Adult_08_facial` in the Microsoft Rocketbox Avatar Library.

- Source: https://github.com/microsoft/Microsoft-Rocketbox
- Copyright: Microsoft Corporation and Rocketbox Studios GmbH contributors
- License: MIT — see https://github.com/microsoft/Microsoft-Rocketbox/blob/master/LICENSE
- Conversion: the source FBX was converted to glTF 2.0 and compressed with
  `FBX2glTF` and `glTF-Transform`; textures were resized for web delivery.

The rendering code uses Three.js, also provided under the MIT license.
