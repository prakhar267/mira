# Mira Ember avatar

`mira-ember.glb` is a compressed derivative of the **Ember** VRM/GLB avatar by
[VTubeMe](https://vtubeme.com/free-vrm-avatars/ember).

with attribution. The local derivative only changes mesh/texture compression
